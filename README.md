# Needle Live Control – downloads

TikTok LIVE gift effects for **Find The Needle**: viewers' gifts add hay, remove hay, or start a
"SAVE ME?" countdown that resets the haystack.

## Get it
1. Download **NeedleLiveControl.exe** from the [latest release](../../releases/latest).
2. Put it in its own folder and open it. (Windows may warn about an unknown publisher – choose *More info → Run anyway*.)
3. In **Mod setup**, press **Install mod**, then start the game from Steam.
4. Enter your TikTok username and press **Connect LIVE**.

The panel checks for updates by itself and shows the version in the top right. When an update is
downloaded you'll see a notice – close and reopen the panel to use it.

Note: while the mod is installed, the game leaves you off its leaderboards. Press **Remove mod** to undo.
